# نور الإسلام (Islamic App)

A React + Vite app with four sections: prayer times (via `adhan`), Quran page viewer, adhkar list, and a Qibla compass.

## Stack
- React 18 + Vite 5
- `adhan` for prayer time calculations
- Geolocation API for user position
- DeviceOrientation API for compass heading

## Structure
- `index.html` — RTL Arabic shell
- `src/main.jsx` — React entry
- `src/IslamicApp.jsx` — main app with all sections

## Workflow
- `Start application`: `npm run dev` on port 5000
